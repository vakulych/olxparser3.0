# OLX Bot 2.0 — Production Ready

> 🚀 **Telegram-бот для пошуку виїдних сделок на OLX з автоматичним мониторингом і системою доступу**

## ✨ Ключові особливості v2.0

### 🔐 Система доступу (NEW!)
- ✅ Нові користувачи **автоматично блокуються**
- ✅ Тільки адміністратор може дати доступ
- ✅ Користувач отримує повідомлення при активації
- ✅ Відслідкування часу активації для кожного користувача

### 📊 Фільтрація по користувачам (NEW!)
- ✅ Таблиця `ads_sent` — кожен товар прив'язаний до користувача
- ✅ Кожен юзер бачить **ТІЛЬКИ СВОЇ** товари
- ✅ Експорт показує **тільки ЙОГ** дані
- ✅ Статистика лічиться **для кожного окремо**

### 📸 Фотографії в повідомленнях (NEW!)
- ✅ Товар відправляється з фото
- ✅ Fallback на текст якщо фото недоступне
- ✅ Підтримка URL і локальних файлів

### 💰 Реальна ринкова ціна
- ✅ Медіана з останніх 14 днів
- ✅ Тільки релевантні товари в розрахунку
- ✅ Sanity check для аномальних цін
- ✅ Реальний ROI, не фейк

### ⚡️ Миттєва відправка
- ✅ Відправка **як тільки товар проаналізований**
- ✅ Без штучних затримок
- ✅ Черговість визначена OLX

## 🚀 Швидкий старт

### Передумови
- Docker & Docker Compose
- Telegram Bot Token (від @BotFather)
- Ваш User ID (Telegram)

### 1️⃣ Клонування
```bash
git clone https://github.com/vakulych/olxparser3.0.git
cd olxparser3.0
git checkout production-v2
```

### 2️⃣ Конфігурація
```bash
cp .env.example .env
```

Отредагуйте `.env`:
```env
BOT_TOKEN=your_token_from_botfather
ADMIN_IDS=123456789,987654321
PARSE_INTERVAL_SECONDS=30
MIN_FLIP_SCORE=60
```

### 3️⃣ Запуск
```bash
docker-compose up -d
```

Перевірте логи:
```bash
docker-compose logs -f bot
```

## 📱 Як користуватися

### 🔓 Для звичайного користувача

1. **Напишіть /start в боті**
   ```
   ❌ Доступ не надано
   ID вашого акаунту: 123456789
   Зв'яжіться з адміністратором
   ```

2. **Адміністратор активує доступ**

3. **Користувач отримує повідомлення**
   ```
   🎉 ДОСТУП К БОТУ ДАН!
   ✅ Додавляйте поискові запити
   ✅ Получайте уведомления о виїдних сделках
   ✅ Отслеживайте прибыль
   ```

### ⚙️ Команди
```
/start — головне меню
/searches — мои поиски
/add iPhone — добавити пошук
/favorite — избранное
/stats — статистика ЙОГ
/settings — настройки
/export — экспорт данных (ТІЛЬКИ ЙОГ)
/help — справка
```

### 🔧 Команди адміністратора
```
/admin_grant 123456789 — дати доступ користувачу
/admin_revoke 123456789 — відкликати доступ
/admin_list — список користувачів
```

## 📊 База даних

### Критичні таблиці

| Таблиця | Описання |
|---------|----------|
| `users` | Користувачи з `is_active` флагом |
| `ads` | ВСІ знайдені товари (глобальна база) |
| **`ads_sent`** | ⭐️ Товари **надіслані кожному користувачу** |
| `searches` | Пошукові запити користувача |
| `favorites` | Вибране користувача |
| `profits` | Записи про прибуток |

**Ключова фішка**: Таблиця `ads_sent` містить посилання `user_id`, тому:
- Експорт показує тільки його товари
- Статистика лічиться окремо
- Немає змішування даних
