# OLX Bot 2.0 — Production Ready

## 🚀 Что нового в v2.0

### ✅ Система доступа (Access Control)
- Новые пользователи **автоматически блокируются**
- Только администратор может дать доступ через команду
- Каждый пользователь получает уведомление при активации

### ✅ Фильтрация по пользователям
- Каждый товар отправляется **только его подписчикам**
- Таблица `ads_sent` — отдельно для каждого юзера
- Экспорт показывает **только его товары**
- Статистика считается **по его данным**

### ✅ Рыночная цена (работает!)
- Медиана из последних 14 дней
- Только релевантные товары в расчете
- Sanity check — отсеиваются аномальные цены
- Реальный ROI, не фейк

### ✅ Фотографии в сообщениях
- Товар отправляется с фото
- Если фото недоступно — отправляется текст
- Поддержка по URL и локальных файлов

### ✅ Миттєва відправка
- Отправка происходит **как только товар проанализирован**
- Нет задержек между обработкой и отправкой
- Временная метка `sent_at` фиксирует момент

## 🔧 Использование

### Для обычного пользователя

1. Пользователь пишет `/start`
2. Получает сообщение: "❌ Доступ не предоставлен"
3. ID показывается в сообщении

### Для администратора

```bash
# Дать доступ
/admin_grant 123456789

# Отозвать доступ
/admin_revoke 123456789

# Список пользователей
/admin_list
```

После `/admin_grant` пользователь получает уведомление:
```
🎉 ДОСТУП К БОТУ ВЫДАН!

Вы получили доступ к OLX Bot. Теперь вы можете:
✅ Добавлять поисковые запросы
✅ Получать уведомления о выгодных сделках
✅ Отслеживать прибыль
```

## 📊 База данных

### Таблицы
- `users` — пользователи с флагом `is_active`
- `ads` — все найденные товары (глобальная база)
- `ads_sent` — **товары отправленные каждому пользователю** ← КРИТИЧНА
- `searches` — поисковые запросы пользователей
- `favorites` — избранные товары
